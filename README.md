# MoscowPrices — оценка стоимости квартир в Москве

Учебный проект с анализом объявлений, регрессией **CatBoost** и веб-интерфейсом на **HTML/CSS/JavaScript + Flask**. Модель использует площадь, число комнат, этаж, время до метро и среднюю цену объявлений у выбранной станции.

**Состояние репозитория:** ноутбук, фронтенд, Flask API, таблица станций и готовая карта опубликованы. Исходного `data.csv`, файла координат `metrocord.csv` и обученной модели `catboost_model.cbm` нет. После клонирования можно открыть интерфейс и карту; для предсказаний нужна модель.

## Подготовка модели

Для обучения нужен исходный датасет. В сохранённом выводе ноутбука у него 22 676 строк и следующие поля:

```text
Price, Apartment type, Metro station, Minutes to metro, Region,
Number of rooms, Area, Living area, Kitchen area, Floor,
Number of floors, Renovation
```

Источник и дата выгрузки `data.csv` в репозитории не указаны. Подменять его произвольным CSV и ожидать сохранённых результатов нельзя.

Если исходные данные доступны:

1. Положите `data.csv` рядом с ноутбуком и замените `pd.read_csv('/data.csv')` на `pd.read_csv('data.csv')`.
2. Выполните ячейки загрузки, очистки, анализа и обучения до блока с `CatBoostRegressor`. Для локального экспорта таблицы станций замените путь `/content/metro_coefs.csv` на `metro_coefs.csv`.
3. После обучения сохраните модель в новой ячейке:

```python
model.save_model("catboost_model.cbm")
```

4. Держите модель и соответствующий ей `metro_coefs.csv` рядом с Flask-файлом `app.py`. При новом обучении таблица должна быть рассчитана из тех же данных.
5. Для повторного построения карты отдельно нужен `metrocord.csv` с полями `Name`, `Latitude`, `Longitude`; исправьте его путь в ноутбуке. Для использования готовой карты этот файл не нужен.

**Не выполняйте ячейку `%%writefile app.py` в каталоге проекта:** она записывает Streamlit-прототип поверх опубликованного Flask API. Для этого прототипа используйте отдельную рабочую папку. Ячейки с `cloudflared` для локального сайта не нужны.

## Запуск API

После подготовки модели из корня репозитория:

```bash
python app.py
```

API слушает `http://127.0.0.1:5000`. В другом терминале запустите статический сервер из раздела просмотра интерфейса.

Пример запроса в PowerShell:

```powershell
$payload = @{
    area = 50
    rooms = 2
    floor = 5
    minutes = 10
    metro = "Пушкинская"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:5000/predict" -Method Post -ContentType "application/json" -Body ([System.Text.Encoding]::UTF8.GetBytes($payload))
```

Поле ответа `prediction` содержит оценку цены в рублях. Название станции должно присутствовать в `metro_coefs.csv`.

## Модель и сохранённые результаты

CatBoost обучается на `log1p(Price)`; API преобразует результат обратно через `expm1`. Разбиение — 80/20, `random_state=42`; параметры включают 1 500 итераций, `depth=10`, `learning_rate=0.03`.

| Метрика из ноутбука | Значение |
| --- | ---: |
| MAE | 1 202 578 ₽ |
| RMSE | 2 388 962 ₽ |
| R² | 0.90 |

Значения приведены из сохранённого вывода и не пересчитывались при обновлении README. **Оценка может быть завышена:** средняя цена по станции (`Metro_coef`) вычисляется на всей выборке до train/test, а тестовая часть также используется для выбора лучшей модели. Для независимой проверки нужны расчёт признака только на обучающих данных и отдельные validation/test.

## Известные ограничения

- Надпись «95% точность» на странице — демонстрационный текст; она не соответствует метрикам регрессии выше.
- В `metro_coefs.csv` поле `Count` содержит относительный ценовой коэффициент, хотя карта использует его как интенсивность. Его нельзя считать количеством объявлений.
- Список станций фронтенда задан вручную и может расходиться с таблицей API.
- API не проверяет полноту и корректность запроса; неизвестная станция или неверные числа могут привести к ошибке. Во фронтенде нет обработки таких ошибок.
- Flask запускается с `debug=True`, CORS разрешён без ограничений. Это конфигурация локальной демонстрации.
- Модель и версии зависимостей не опубликованы; полный запуск с чистого клона пока не воспроизводится.
